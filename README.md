# Investment Banking M&A Screener (Excel VBA)

This project is an Excel VBA-based screening tool designed to support M&A and comparable company analysis.

## Key Features
- Import company financial data from CSV files
- Screen companies using LTM financial and valuation metrics
- Categorise comparable metrics for analysis
- Export screened results for further modelling

## Data
The tool uses sample LTM data compiled from publicly available sources such as Finviz, Yahoo Finance, and The Wall Street Journal.  
All data is for educational purposes only.

## Use Case
Designed to replicate entry-level Investment Banking workflows, particularly in M&A and valuation screening.

## Tech Stack
- Excel VBA
- CSV data handling

## Disclaimer
This project uses sample data and is not intended for investment advice.
